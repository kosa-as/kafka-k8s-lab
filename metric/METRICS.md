# 当前 Prometheus 指标清单

> 这是从当前真实环境的 Prometheus HTTP API 导出的指标名称快照，不是“所有 Kafka 版本理论上可能存在的指标”。Kafka 的 MBean、topic 和 partition 变化后，清单也可能变化。Prometheus 本地 TSDB 还会保留配置变更前的历史指标名；旧名称可能在历史时间范围内仍可查询，但不再产生新样本。

- Prometheus 地址：`http://localhost:9090`
- API：`GET /api/v1/label/__name__/values`
- 抓取任务：`kafka-brokers`
- Broker 数量：3
- 本次快照中的指标族数量：1309（包含规则变更后的 `kafka_log_logendoffset`）
- 快照时间：2026-09-23（本地环境）

## 如何查询

在 Prometheus Graph 页面输入指标名即可查询，例如：

```promql
up
jvm_memory_used_bytes
kafka_server_brokertopicmetrics_messagesin
```

按前缀筛选：

```promql
{__name__=~"kafka_.*"}
{__name__=~"jvm_.*"}
{__name__=~"process_.*"}
```
